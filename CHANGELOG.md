# Changes

## 0.2.0

The first public version.

- Controls the air conditioners on an AC Freedom account from the menu bar: power, temperature, mode, fan speed,
  airflow, and the extras each model has.
- Lists the units shared from another account along with the account's own.
- Offers each model only the modes, fan steps and features it has.
- Reads the units only while its window is open, unless you turn on Keep Menu Bar Updated.
- Report a Problem…: an anonymous report that you can read in full before you send it.
- For Apple-silicon and Intel Macs, with macOS 14 or later.
